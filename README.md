# Sawariya Confectionary

FastAPI + SQLite CRUD application for managing confectionery products.

## Run

1. Create/activate a virtual environment (optional but recommended).
2. Install:
   pip install -r requirements.txt
3. Start:
   uvicorn main:app --reload
4. Open:
   http://127.0.0.1:8000

## Default login users

- admin / admin123
- mangal / mangal123
- user3 / user3123

Change these credentials before real-world deployment.

## Features

- Home page
- Login/logout
- Three seeded users
- Product search
- Add product
- Edit/update product
- Delete product
- SQLite database
